# GURPS Roll Statistics

A Foundry VTT module for the GURPS 4e Game Aid system. It records the results of
GURPS rolls (success rate, criticals, margins of success and failure) for each
character, and can announce critical successes, critical failures and bad misses
in chat.

Requires Foundry VTT v14 and the GURPS Game Aid system.
